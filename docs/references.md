## 적용한 편집 기준

1. 첫 화면에서 대회 문제, 팀, 성과와 접근법을 파악할 수 있게 한다.
2. 실험은 **질문 → 바꾼 점 → 관찰 결과 → 다음 결정**으로 정리한다.
3. 성능이 오르지 않은 시도도 다음 선택을 설명하는 근거로 남긴다.
4. 내부 검증 점수와 실제 제출 점수를 구분하고, 날짜·실험 순서를 확인할 수 없으면 임의로 만들지 않는다.
5. 실행·데이터 안내는 별도 문서에서 다루고, 대회 진행 이야기가 README의 중심이 되게 한다.
