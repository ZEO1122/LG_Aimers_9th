# 팀 기여와 출처

이 프로젝트는 LG Aimers 9기 **떡잎마을방범대**의 팀 연구를 바탕으로 합니다. 공개본은 공통 전처리 구현과 테스트, 연구 과정 설명을 선별해 구성했습니다.

## 기여 표시

원본 연구는 EDA, 전처리, ML·DL 모델 실험, 검증, 앙상블과 제출 준비를 팀 단위로 진행한 기록입니다. 과거 README의 역할 배정표만으로 실제 최종 기여나 각 파일의 단독 저자를 확정할 수 없어, 이 공개본에는 개인별 성과나 GitHub 계정을 임의로 대응시키지 않았습니다.

개인 포트폴리오에 활용할 때는 본인이 실제 담당한 파일·실험과 검증 가능한 작업 기록을 근거로 기여를 설명해야 합니다. 팀 전체의 결과를 개인 단독 성과로 표현하지 않습니다.

## 포함한 코드의 출처

| 공개 경로 | 원본 연구 저장소의 출처 |
|---|---|
| `Preprocess/common/*.py` | 동일 경로의 공통 전처리 소스 |
| `Preprocess/run.py` | 동일 경로의 입력 스키마·동작 확인 실행기 |
| `Preprocess/tests/test_preprocessing_contract.py` | 동일 경로의 합성 입력 계약 테스트 |
| `Preprocess/requirements.txt` | 동일 경로의 전처리 의존성 명세 |

기존 소스의 저작자 표시가 있는 경우 이를 유지합니다. README와 `docs/`는 선별된 공개 범위에 맞춰 새로 작성한 설명이며, 과거 실험의 출처 경로는 [대표 실험](experiments.md)에 기록했습니다. 그 경로는 비공개 원본의 출처 표기이며 공개본의 실행 경로가 아닙니다.

## 데이터와 외부 프로젝트

- 대회 설명과 데이터 제공 주체에 관한 정보는 [공식 대회 홈페이지](https://dacon.io/competitions/official/236743/overview/description)를 참고합니다.
- 대회 원본 데이터, 선수별 학습 통계, 예측 결과와 학습 모델은 이 공개본에 포함하지 않습니다.
- 공개 코드의 직접 의존성은 NumPy와 pandas이며, 각 프로젝트의 권리와 라이선스는 해당 프로젝트에 귀속됩니다.
- CatBoost 등 모델 이름은 과거 연구를 설명하기 위해 등장합니다. 해당 모델 구현이나 학습 가중치를 이 공개본에서 배포하지 않습니다.

## 이용 범위

팀 코드의 재배포·재사용 허용 범위와 대회 공개 조건을 일괄적으로 허가하는 라이선스를 임의로 부여하지 않았습니다. 공개 열람 가능 여부와 재사용 허가는 구분되며, 저장소 공개가 데이터나 외부 프로젝트에 대한 권리를 새로 부여하지 않습니다. 공개 범위에 대한 상태는 [공개 기준](publication.md)을 참고하세요.
