# 대표 실험과 판단

아래 내용은 **원본 연구 저장소에 이미 기록된 결과를 선별한 요약**입니다. 공개본을 만드는 과정에서 학습이나 성능 평가를 다시 실행하지 않았습니다. 실험 코드·데이터·OOF 예측·모델은 이 저장소에 포함되지 않으며, 어느 수치도 첨부 리더보드 점수의 직접적인 재현 근거로 제시하지 않습니다.

## 1. ML-015: 튜닝 전에 비교 기준 고정

새 설정의 효과를 평가하려면 기존 모델의 데이터·피처·학습 조건부터 재현할 수 있어야 합니다. ML-015는 CatBoost의 FULL 244개 피처, 2022–2024 시간 순서 검증, seed 17·42·2026을 고정하고 이전 기준 실험과 비교했습니다.

원본 기록은 최대 예측 차이 `2.9802e-8`, 최대 Brier 차이 `1.59e-10`으로 `LOCKED` 판정을 보고합니다. 초기에는 예측 허용오차와 Brier 허용오차가 일관되지 않아 실패했고, 확률의 제곱 오차 차이에 대한 상계에 맞춰 검사 기준을 수정했습니다. 모델 자체의 변경과 검사 기준의 수정을 구분한 사례입니다.

| 검증 연도 | 기록된 Brier |
|---|---:|
| 2022 | 0.243154184 |
| 2023 | 0.252099822 |
| 2024 | 0.247747026 |

Brier는 낮을수록 좋습니다. 연도별 편차가 크므로 하나의 결합 평균만으로 안정성을 판단하지 않았습니다. 3-seed 평균의 pooled Brier 개선은 seed 42 대비 `0.000024881`이었지만, 2023은 평균적으로 악화했고 2024의 개선 신뢰구간은 0을 포함했습니다. seed 평균도 연도별 개선을 보장하지 않습니다.

원본 출처: `Experiment/ML/EXP_ML_015_reproducible_baseline_contract/README.md`.

## 2. ENS-044: 복잡한 조건 분기 대신 고정 비율 혼합 검토

2022·2023에서 후보와 가중치를 정한 뒤, `0.75 CatBoost + 0.25 ENS-032`의 상수 혼합을 2024에 적용했습니다. 평균 개선이 더 큰 다른 조합도 있었지만 경기 유형·저표본 구간·확률 보정 조건을 함께 고려했습니다.

| 2024 지표 | CatBoost 기준 | ENS-044 후보 |
|---|---:|---:|
| Brier | 0.247747026 | 0.247714981 |
| ECE10 | 0.009536 | 0.010293 |

기록상 Brier는 개선됐지만 ECE10은 악화했습니다. 따라서 전체 확률 예측의 제곱 오차 개선과 확률 보정 개선을 같은 결론으로 취급하지 않았습니다. 2024는 이전 실험에서도 관찰했으므로 이 결과는 **사후 감사**이며, 독립적인 최종 평가로 볼 수 없습니다.

원본 출처: `Experiment/Ensemble/Existing_ENS/EXP_ENS_044_locked_global_blend/README.md`.

## 3. ENS-045: 실행 검증 통과와 실제 제출 결정을 분리

ENS-044의 고정 구성을 전체 학습과 독립 실행 패키지로 옮기는 연구입니다. 원본 기록에서는 단일 행·행 순서·배치 분할, 구성 모델별 예측 일치, 실제 ZIP의 격리 실행과 결정적인 ZIP 생성 검사를 보고합니다. 원래 계산과 패키징된 계산의 최대 절대 오차는 `1.11e-16`로 기록됐습니다.

하지만 최종 기술 상태 `SUBMISSION_READY`와 성능 상태 `FALLBACK_ONLY_DO_NOT_SUBMIT`은 달랐습니다. 재구성한 검증 성능이 당시 제출 기준 후보보다 낮아 **예비안으로 보관했고, 이 실험의 DACON 업로드는 수행하지 않았다고 기록**돼 있습니다.

이 사례의 의미는 패키지를 만들었다는 사실 자체가 아니라, 실행 가능성과 성능 채택 여부를 별도의 근거로 판단했다는 점입니다. ENS-045를 팀의 최종 제출 모델이나 1,162.43634점의 모델로 소개하지 않습니다.

원본 출처: `Experiment/Ensemble/Existing_ENS/EXP_ENS_045_ens044_production_runtime/README.md`.

## 회고

- 피처나 모델을 더하기 전에 재현 가능한 비교 기준을 고정해야 작은 성능 차이를 해석할 수 있습니다.
- 연도·경기 유형별 결과를 함께 봐야 평균 개선이 특정 구간에 집중되는 현상을 발견할 수 있습니다.
- 반복 사용한 검증 데이터는 미관측 평가가 아닙니다. 후보 선택과 결과 해석에 이 한계를 남겨야 합니다.
- 합성 입력과 실행 일치성 검사는 동작의 근거이며, 숨은 평가 데이터에 대한 일반화 성능을 입증하지 않습니다.

이 공개본의 [합성 테스트](../Preprocess/tests/test_preprocessing_contract.py)는 공통 전처리 계약을 직접 확인하는 진입점입니다. 위 모델 실험들의 전체 재현은 제공하지 않습니다.
