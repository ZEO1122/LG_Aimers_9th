# EDA에서 단일 모델 검증까지

팀의 모델링은 **선수의 과거 제구 수준을 기준 확률로 만들고, 경기 상황으로 얼마나 더 설명할 수 있는지 확인하는 과정**이었다. 트리 모델과 딥러닝을 함께 시도했지만, 모델 크기나 한 해의 최고점보다 미래 시즌과 경기 유형이 달라져도 개선이 유지되는지를 중요하게 봤다.

이 문서는 실험을 의사결정 흐름으로 묶은 회고다. 실험 ID 순서가 모든 작업의 실제 실행 순서를 뜻하지는 않는다. 앙상블과 제출 후보로 이어지는 과정은 [후속 실험 기록](experiments.md), 검증 설계는 [방법론](methods.md)에서 이어진다.

## 1. EDA: 한 투구를 어떤 정보로 설명할 것인가

예측 대상은 한 투구의 `control_success`다. 이미 던진 공의 위치를 보고 성공 여부를 분류하는 문제가 아니라, **던지기 직전의 상황과 과거 기록으로 성공 확률을 예측**해야 했다. 따라서 EDA도 단순 상관계수보다 관측 시점, 선수 이력의 길이, 시즌 변화에 초점을 맞췄다. [E1]

| EDA에서 확인한 점 | 모델링 질문 | 이어진 설계 |
|---|---|---|
| 성공률이 2019년 56.47%에서 2024년 48.61%로 하락 | 과거 평균을 그대로 미래에 적용해도 되는가? | 시간 순서 검증, 최근 시즌 가중치, 기준 확률과 잔차 분리 |
| Futures(`F`)와 Regular(`R`)의 성공률 관계가 2023년 이후 바뀜 | 전체 평균이 좋아도 특정 경기 유형에서 실패하지 않는가? | 연도별 F/R 진단, FT의 F 보정 실패 분석 |
| 투수·타자 ID의 범주 수가 많고 새 시즌 선수 구성이 달라짐 | 선수 이름에 해당하는 ID를 외우는가, 이력을 학습하는가? | 희소 ID pooling, 미지 ID 처리, ID 영향 진단 |
| 최근 1·3·5경기 기록이 없거나 짧은 사례가 존재 | 최근 성공률을 어느 정도 믿을 것인가? | 이력 표본 수·가용성 플래그, 장기 기록으로의 축소 |
| `asof_*`는 현재 투구 이전의 누적 기록 | 강한 선수 이력 신호를 사전 정보로 사용할 수 있는가? | 누적 제구·구속·구종 구성과 최근 폼의 차이 |
| main과 TrackMan은 선수 ID 체계가 다름 | 물리 측정 이력을 어떻게 연결할 것인가? | 동일 ID로 단순 조인하지 않고 후속 실험에서 연결 가정과 과거 시즌 집계를 별도 검토 |

여기서 두 종류의 ‘새 선수’를 구분했다. **현재 시점 누적 관측 수가 0인 cold-start**와 **이전 시즌 학습 집합에 없던 선수**는 다른 집단이다. 시즌 도중 기록이 쌓이면 이전 시즌에는 없던 선수도 `asof_*` 이력을 가질 수 있다. 실험별 신규 선수 지표는 각 실험의 정의 안에서 해석했다.

EDA의 초기 TrackMan 결론은 공식 연결표 없이 직접 결합하지 말자는 것이었다. 이후 모델의 추정 연결·이력 집계는 별도 모델링 선택이며, 공식 선수 매핑을 제공받았다는 뜻이 아니다. 이 연결 가정을 모든 피처와 함께 당연한 사실로 취급하지 않은 점도 후속 진단의 출발점이었다.

### 야구 상황을 피처 가설로 바꾸기

| 피처 묶음 | 구체적인 입력·변환 | 검증하려던 가설 |
|---|---|---|
| 장기·시즌 선수 이력 | 투수·타자의 과거 성공률, 누적 관측 수, 시즌 누적 기록 | 안정적인 제구 수준을 설명하되 적은 표본의 극단값을 줄일 수 있다 |
| 최근 폼 | 직전 1·3·5경기 기록, 최근 성공률과 장기 성공률의 차이 | 최근 상태 변화가 장기 평균에 없는 신호를 준다 |
| 카운트·주자·점수 | 볼·스트라이크 조합, 아웃, 주자 상태, 점수 차 | 같은 선수라도 경기 상황에 따라 제구 확률이 달라진다 |
| 손 조합·팀 | 투타 좌우 조합, 팀·상대 팀 맥락 | 개인 이력이 부족할 때도 적용 가능한 집단 신호가 있다 |
| 투구 성향 | 과거 시즌 구속·회전·구종 구성의 집계 | 선수 ID보다 지속적인 투구 특성을 표현할 수 있다 |
| 신뢰도 | 이력 유무, 표본 수, 최근 기록 가용성 | 똑같은 성공률이라도 관측 5회와 500회를 다르게 취급해야 한다 |

이 묶음이 모두 최종 모델에 채택된 것은 아니다. 이후 실험은 묶음을 추가하거나 줄이고, 같은 입력을 다른 모델에 전달하면서 실제 증분 효과를 확인했다.

## 2. 기준선: 과거 제구 수준과 잔차를 분리하기

초기 `EXP-ML-002`는 공식 시즌 누적 정보와 이전 시즌 TrackMan 이력을 결합하고, 잔차 CatBoost 두 개와 직접 예측 CatBoost 한 개를 고정 비율로 섞었다. 기록된 2019–2023 학습 → 2024 검증 환산 점수는 **870.72**, 해당 실험 README에 기록된 Public 점수는 **1,063.2042268775**다. 이 수치는 이후 모든 모델의 공통 검증 점수나 최종 팀 점수가 아니다. [M2]

다른 실험에서 공통 기준으로 사용한 `Formula`는 투수·타자 성공률을 그대로 평균내지 않고, 표본이 적을수록 prior 쪽으로 축소한 확률이다. `EXP-ML-009`의 기준은 투수 확률 70%와 타자 확률 30%를 결합한다. 학습 모델은 이 기준 전체를 다시 맞히거나, 기준이 놓친 잔차만 보정하는 역할로 나눠 비교했다. [M9]

이 선택에는 구체적인 실패 근거가 있었다. 직접 예측 XGBoost의 2024 예측 평균은 약 **0.5362**, 실제 평균은 약 **0.4861**이었다. 과거 관계를 학습해도 미래 시즌의 확률 수준을 잘못 잡으면 손실이 커졌다. 후속 모델은 단순히 깊이를 늘리기보다 **기준 확률을 얼마나 보존하고 얼마나 수정할지**를 실험했다.

## 3. 트리 모델: 최근성, 희소 ID, 보정 강도를 나눠 확인

아래 pooled Brier는 별도 표기가 없으면 `2019–2021 → 2022`, `2019–2022 → 2023`, `2019–2023 → 2024`의 전체 검증 행 **746,504개**를 합친 결과다. Brier는 낮을수록 좋다. 같은 평가 행을 사용해도 피처 구성과 선택 과정은 다르므로 단일 리더보드처럼 읽지 않는다.

| 실험 | 고정한 조건과 바꾼 가설 | 기록된 결과 | 판단 |
|---|---|---|---|
| `EXP-ML-007` | exact-v6 수치형 270개·범주형 17개를 고정하고 LightGBM과 XGBoost 직접 예측 비교 | pooled Brier: LightGBM **0.24783045**, XGBoost **0.25117732** | 이 설정에서는 LightGBM을 후속 기준으로 선택 |
| `EXP-ML-007` 후속 | LightGBM의 과거 시즌 가중치를 감쇠 | 감쇠 0.50에서 **0.24772394**, 0.25에서 **0.24775762** | 최근성 반영은 유효했지만 더 강한 감쇠가 항상 좋지는 않았음 |
| `EXP-ML-008` | LightGBM·감쇠 0.50을 고정하고 희소 범주를 `RARE`로 묶는 강도 변경 | 범주 cap 255 → 32에서 **0.24772394 → 0.24719734** | cap 32 선택. cap 16과 추가 leaf 규제는 더 좋지 않았음 |
| `EXP-ML-009` | 직접 XGBoost 대신 Formula 잔차를 학습하고 보정 비율 제한 | Formula **0.24729672** → depth 2, 3-seed, 보정 10%의 **0.24714075** | 작은 잔차 모델 선택. 강한 보정은 연도·F·신규 투수 조건에서 탈락 |
| `EXP-ML-010` | DCN에서 고른 `CORE+G08` 피처를 CatBoost에 그대로 이전 | pooled는 **0.247656096 → 0.246653959**로 개선하나 2024는 **0.247747026 → 0.247804327**로 악화 | 피처 축소안 기각. 모델 간 피처 선택의 자동 전이는 성립하지 않음 |
| `EXP-ML-024` | FULL-244 기준에서 별도의 5-seed 평균 후보 확인 | 2024 전체 Brier gain **+0.000006760**, F gain **−0.000010340**, 개선 seed **1/5** | 전체 평균의 미세 개선만으로 채택하지 않음 |
| `EXP-ML-025` | FULL-244·나머지 설정을 고정하고 `random_strength` 변경 | `RS_0` 2024 Brier **0.247742629**; 기준 대비 gain **+0.000004397**, F는 악화 | 유망 후보로 기록하되 공식 단일 모델 기준은 `EXP-ML-015` 유지 |

ML 표의 출처는 [M7–M25]다. `gain`은 **기준 Brier − 후보 Brier**이므로 양수가 개선이다.

### 희소 ID를 줄인 효과와 남은 약점

`EXP-ML-008`의 cap 32는 `RARE`와 `UNKNOWN`을 포함한 최대 범주 수다. 학습 fold에서 빈도가 높은 30개 범주를 남기고 나머지를 묶었다. 선수 ID·매치업을 세밀하게 구분하는 것보다 수치 이력을 더 활용하게 하려는 가설이었다.

세 검증 연도 전체에서는 개선했지만 F 경기 Brier는 부모 실험 대비 **0.00022745** 악화했다. 따라서 이 실험의 선택안은 범주 처리 가설을 지지하는 내부 후보였으며, 모든 하위 집단을 개선한 최종 모델로 기록하지 않았다. [M8]

### pooled 최고점을 기각한 이유

`EXP-ML-010`의 축소 모델은 2023에서 크게 좋아져 pooled 성능을 끌어올렸지만 2022와 2024에서 악화했다. `EXP-ML-025`도 rolling 개선의 상당 부분이 2023 Futures에서 발생했고, 2024 전체 gain의 투수 단위 bootstrap 95% 구간은 **[−0.000016535, +0.000026588]**로 0을 포함했다.

이 과정에서 팀이 배운 것은 “평균이 낮아졌는가” 외에 “어느 해·어느 경기 유형이 그 개선을 만들었는가”를 함께 봐야 한다는 점이다. 결과를 본 뒤 안전 기준을 완화하거나 확인용 연도에 맞춰 중간 파라미터를 추가 탐색하지 않았다. [M10, M25]

## 4. FT-Transformer: 더 복잡한 상호작용이 미래에도 유효한가

트리 모델과 같은 exact-v6 피처에서 predictor를 FT-Transformer로 바꾸고, Formula를 입력 토큰으로 줄지 출력 기준으로 고정할지 비교했다. 이후 최근성 gate, 미지 선수 대응, 이력 압축, 경기 유형별 보정으로 질문을 좁혔다.

### 직접 예측에서 제한된 잔차로

아래 결과는 **전체 행·1-seed**, 2024에서 정한 설정을 동결한 뒤 2022–2024 rolling 검증으로 다시 확인한 기록이다. 세 연도를 사전에 모두 남겨 둔 독립 holdout 결과라는 의미는 아니다. 표의 값은 각 연도 Brier다. [F1]

| 실험 | 시도 | 2022 | 2023 | 2024 | 해석 |
|---|---|---:|---:|---:|---|
| Formula | 선수 이력 기반 기준 확률 | 0.24539847 | 0.24826103 | 0.24821584 | 보정의 비교 기준 |
| `EXP-FT-001` | Formula도 하나의 토큰으로 제공하고 확률 전체를 예측 | 0.24372946 | 0.25080059 | 0.24787430 | 2024 개선만 보면 놓칠 2023 실패가 드러남 |
| `EXP-FT-002` | Formula logit에 제한된 FT 잔차를 추가 | 0.24389630 | 0.24836913 | 0.24799189 | 직접 예측의 2023 실패를 줄였지만 Formula를 모든 해에서 이기지는 못함 |
| `EXP-FT-003` | 최근성에 따른 잔차 gate | 0.24391761 | 0.24844425 | 0.24797044 | 2024는 002보다 개선, 2023은 악화 |
| `EXP-FT-008` | 조건부 잔차 gate | 0.24385607 | 0.24877252 | 0.24787368 | 2024 개선폭과 연도 안정성이 같은 방향이 아님 |

`EXP-FT-002`의 마지막 잔차 층은 0으로 초기화했다. 학습 시작 시 Formula와 같은 예측을 하게 하고, FT는 최대 `0.25 × tanh(·)`의 logit 보정만 더했다. 이 구조는 새로운 모델이 기존 기준을 처음부터 무너뜨리는 것을 줄였지만, 시간 변화 자체를 해결하지는 못했다. [F2]

### 이력의 표현을 바꾸고 전체 행에서 재확인

`EXP-FT-013`은 이력 피처를 통째로 버리는 대신 의미가 비슷한 항목끼리 압축했다. Formula 관련 이력 95개를 장기 투수·시즌 투수·타자·최근 폼·구종 구성 등의 11개 그룹으로 나눠 PCA 36개 성분으로 바꾸고, 나머지 수치형 175개와 범주형 17개는 유지했다. 작은 계산 예산의 탐색과 전체 행 재검증을 구분해 `EXP-FT-017`로 이어갔다. [F3]

| 전체 행 3-seed 실험 | 2022 Brier | 2023 Brier | 2024 Brier | 결과 |
|---|---:|---:|---:|---|
| `EXP-FT-017` Domain PCA 재검증 | 0.24408461 | 0.24876498 | 0.24794961 | 2023이 Formula보다 **0.00050395** 악화해 승격 실패 |
| `EXP-FT-018` F는 Formula, non-F는 FT017 | 0.24522112 | 0.24810836 | 0.24793348 | 세 연도 Formula 대비 개선. 단, 사후 원인 확인용 결과 |

`EXP-FT-018`의 의미는 더 좋은 gate를 끝없이 찾았다는 데 있지 않다. **F에서 학습한 잔차를 아예 적용하지 않으면 실패가 줄어드는가**를 확인했다. 2023의 오류는 줄었지만, 그 대가로 2022 F에서 얻던 큰 이득도 포기했다. [F4]

이 규칙은 EDA와 2023·2024 실패를 본 뒤 설계했으므로 독립적인 채택 근거로 취급하지 않았다. 전체 행 × 3개 연도 × 3개 seed에서 라우팅 검증과 메커니즘 기준은 통과했지만, 기록상 `promotion_ready`와 `approved_submission`은 모두 false다.

### 전문 모델로 분리해도 좋아지지 않은 실험

`EXP-FT-019`에서는 F를 추론에서만 제외하는 데서 더 나아가 학습에서도 제외했다. 전체 데이터로 전처리하고 non-F만 학습하는 안과, 전처리부터 non-F만 쓰는 안을 비교해 학습 간섭과 전처리 간섭을 분리했다.

순수 non-F specialist의 pooled non-F Brier는 **0.248224**, 기존 FT018은 **0.248154**였다. 차이 약 **+0.000070**의 투수 단위 bootstrap 95% 구간도 **[+0.000046, +0.000097]**로 악화 방향이었다. F를 제거하면 항상 non-F가 좋아진다는 가설은 지지되지 않아 전문 모델로 교체하지 않았다. [F5]

후속 `EXP-FT-020`은 모델 입력 그룹을 중립화하거나 유사한 학습 사례의 값으로 교체해 예측 민감도와 실제 손실 변화를 분리했다. 달력·도메인, 장기 선수 수준, 시즌 이력에 대한 의존은 컸지만, 특정 그룹을 안정적인 신호 또는 지름길 학습으로 확정하지 못했다. **예측이 크게 변한다는 사실만으로 중요하거나 해로운 피처라고 결론내리지 않았다.** [F6]

## 5. RealMLP: 도메인 피처와 트리 예측의 결합

RealMLP 계열에서는 기본 경기 상황부터 시작해 최근 폼, 야구 상황 6개 묶음, Formula anchor, 트리 anchor, OOF stacking을 비교했다. 아래는 원본 README에 기록된 **수정 후 fresh-kernel 재실행 결과**다. 2022·2023에서 epoch와 보정 설정을 선택하고, 실험별로 고정한 설정을 2024에서 평가했다. **BSS는 높을수록 좋으며, 이 표는 Public 점수가 아니다.** [R1]

| 실험 | 가설·변경 | 2024 BSS | 관찰과 판단 |
|---|---|---:|---|
| `EXP-RMLP-001` | 경기 상황 수치형·범주형의 기본 RealMLP | 0.003779 | 계열 내 비교 기준 |
| `EXP-RMLP-002` | Formula 기준 위에 잔차 보정 | 0.002757 | 기본 모델보다 낮아 anchor만으로 개선되지 않음 |
| `EXP-RMLP-004` | Formula와 target-encoding logit 합의, 전체 절편 보정 | 0.004817 | 이 설정에서는 확률 수준 보정이 유효 |
| `EXP-RMLP-006` | 최근성·카운트·손 조합·주자·점수·팀의 6개 도메인 묶음 | 0.003719 | 도메인 피처 추가만으로 기본 모델을 넘지 못함 |
| `EXP-RMLP-007` | 최근 1·3·5경기 제구율 변화량 | 0.002778 | 최근 폼의 표현을 늘려도 단독 개선은 확인되지 않음 |

| `EXP-RMLP-012` | CatBoost·LightGBM·Formula anchor와 도메인 피처 결합 | **0.006618** | 수정 후 16개 실험 중 기록된 최고 2024 BSS; 내부 환산 661.83 |

표의 방향은 “트리 예측을 어떻게 신경망에 전달하느냐”가 중요했음을 보여준다. anchor로 확률 수준을 유지하는 안은 개선했지만, OOF logit을 피처로 쌓는 방식이나 target encoding 중심의 표현은 같은 결과를 만들지 못했다. 여러 요소를 함께 바꾼 실험도 있어, 이 표만으로 각 요소의 독립적인 기여를 분해할 수는 없다.

재실행 전에는 GBDT 모델 dispatch, 첫 시즌 random OOF, validation/test target encoding 적용 문제가 있었다. 원본 기록은 그 영향을 받은 이전 수치를 비교에서 제외한다고 명시한다. 따라서 높은 과거 수치와 수정 후 수치를 섞지 않고 위 결과만 사용했다. 또한 16개 실험의 2024 결과를 모아 비교한 시점에서는 2024가 계열 전체의 미사용 평가셋으로 남아 있지 않다는 한계가 있다.

### SAINT: 행 사이 attention이 허용되는가

SAINT 계열에서는 모델의 성능뿐 아니라 attention이 어느 범위의 정보에 접근하는지 확인했다.
실제 데이터 재실행에서 intersample attention이 다른 평가 행에 따라 예측을 바꾸는 현상을 재현한 뒤,
production SAINT-s에서는 한 행 내부의 피처 attention만 사용하고 행 사이 attention을 비활성화했다.
2024 BSS는 **0.002040**, 내부 환산 점수는 **203.99**로 기록됐다.
셔플·배치 확장·단일 행에서도 같은 예측을 유지하는지 검사한 사례다. 원본 `README.md`의 SAINT 재실행 기록이 근거다.

## 6. 다음 단계로 가져간 판단

- **선수 이력은 기준 확률을 만드는 출발점이었다.** 최근성·표본 수와 함께 다뤄야 했고, 선수 ID를 세밀하게 남기는 것이 항상 유리하지는 않았다.
- **트리와 신경망 모두 시즌 변화에서 실패했다.** 예측 수준을 anchor로 보존하고 보정 강도를 제한하는 방식이 유용했지만, 모든 경기 유형의 변화를 해결하지는 못했다.
- **같은 피처 선택이 다른 모델에서도 통하지 않았다.** DCN용 축소 피처의 CatBoost 이전과 non-F 전문 학습은 결과를 확인하고 기각했다.
- **실패 원인 분석과 채택 증거를 구분했다.** F fallback처럼 설명력이 있는 사후 실험도 새로운 미래 구간의 성능을 보장하지 않는다.
- **앙상블에는 단일 최고점 외의 근거가 필요했다.** 연도·집단별 실패 방향과 예측 오차의 차이를 후속 결합 실험의 질문으로 가져갔다.
